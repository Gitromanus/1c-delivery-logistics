# 1C Delivery Logistics

Рабочее место логиста для доставки.

- Заявки приходят из **1С:УТ 11** (Реализация товаров и услуг, адрес доставки)
- Зоны, машины, привязка ТС к зонам
- Сборка рейсов с учётом грузоподъёмности
- Подсказки при перегрузе / недогрузке

Стек: **PHP + MySQL** (Beget).

## Быстрый старт на Beget

1. Создайте БД MySQL в панели Beget.
2. Импортируйте `sql/schema.sql`.
3. Скопируйте `config.example.php` → `config.php`, укажите доступ к БД и `api_key`.
4. Залейте содержимое `public/` в нужную папку сайта (или весь проект, если document root = `public/`).
5. Откройте сайт — рабочий стол логиста.
6. Админка: `/admin/` (пароль из `config.php`).

## API для 1С

`POST /api/orders.php`

Заголовок или поле: `X-Api-Key: ваш_ключ`

```json
{
  "external_id": "РеализацияУТ-00018421",
  "number": "РН-18421",
  "doc_date": "2026-09-04",
  "partner": "ООО Ромашка",
  "address": "пос. Молодёжный, ул. Ленина, 12",
  "weight_kg": 120,
  "amount": 15400,
  "comment": ""
}
```

Повтор с тем же `external_id` обновляет заявку (идемпотентно).

Можно отправить массив: `{ "orders": [ {...}, {...} ] }`.

## Пример вызова из 1С (BSL)

```bsl
HTTP = Новый HTTPСоединение("your-domain.ru", 443, , , , 30, Новый ЗащищенноеСоединениеOpenSSL());
Заголовки = Новый Соответствие;
Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
Заголовки.Вставить("X-Api-Key", "ваш_ключ");

Тело = "{\"external_id\":\"РН-18421\",\"number\":\"РН-18421\",\"doc_date\":\"2026-09-04\",\"partner\":\"Тест\",\"address\":\"пос. Молодёжный, ул. Ленина, 12\",\"weight_kg\":120}";
Запрос = Новый HTTPЗапрос("/api/orders.php", Заголовки);
Запрос.УстановитьТелоИзСтроки(Тело, КодировкаТекста.UTF8);
Ответ = HTTP.ОтправитьДляОбработки(Запрос);
```

Подставьте свой домен и путь, если сайт не в корне.

## Структура

```
public/           — веб-корень
  index.php       — рабочий стол логиста
  api/            — API
  admin/          — зоны, машины, сборка рейсов
  assets/
sql/schema.sql
config.example.php
src/              — PHP-классы (подключаются из public)
```
