# 1C Delivery Logistics

Рабочее место логиста: заявки из 1С УТ 11, зоны, машины, рейсы.

## Beget (как у вас сейчас)

Всё в **public_html**:

```
public_html/
  index.php
  bootstrap.php
  config.php          ← ваш файл с паролями БД
  src/                ← ОБЯЗАТЕЛЬНО залить
    Database.php
    ZoneMatcher.php
    TripBuilder.php
  api/
  admin/
  assets/
```

1. Импорт `sql/schema.sql` в MySQL.
2. `config.php` уже рядом с `index.php` — ок.
3. Залейте папку **`src`** из репозитория (`public/src/` → `public_html/src/`).
4. Обновите `bootstrap.php` с GitHub.
5. Смените `api_key` в config на свой секрет.

Откройте `http://z951445o.beget.tech/`

## Порядок маршрутов (шаблон по зоне)

Порядок объезда клиентов запоминается автоматически:

1. Оператор перетаскивает заявки в нужном порядке в рейсе на рабочем столе (drag & drop).
2. Порядок **клиентов** сохраняется как шаблон зоны (таблица `route_templates`).
3. При следующей сборке рейсов по этой зоне («Пересобрать») заявки раскладываются
   по сохранённому порядку клиентов. Новые клиенты, которых нет в шаблоне,
   добавляются в конец.

Однократная ручная расстановка достаточно — на следующие даты она применяется сама.

Миграция: `sql/migrate_route_templates.sql` (для существующей базы).

## Объединённые рейсы (одна машина на несколько зон)

Если в админке машина привязана к нескольким зонам («Привязка»), то при
малой загрузке — когда суммарный вес заявок этих зон влезает в
вместимость машины — «Пересобрать» создаёт **один объединённый рейс**
по всем этим зонам. Порядок объезда: сначала заявки первой зоны (по
шаблону), затем второй и т.д. Такой рейс помечается на рабочем столе
(«Объединённый рейс: Зона А + Зона Б»).

Если суммарный вес не влезает в машину (большая загрузка), зоны
обслуживаются раздельно, как обычно — по своим машинам.

Ручная перестановка заявок в объединённом рейсе шаблон зоны не меняет.

Кнопка «+» в шапке рейса (у названия машины) — то же самое вручную, без
админки и на любую дату: оператор выбирает район, и его заявки (из чужих
рейсов дня и нераспределённые) перетягиваются в этот рейс, рейс получает
пометку «Объединённый рейс: …». Выбранный район в списке помечен галочкой
— повторный клик убирает его обратно (заявки выходят в «Нераспределённые»).
